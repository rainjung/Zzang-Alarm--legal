# プライバシーポリシー

本ポリシーは、Zzang Alarm（以下「本サービス」）が利用者の個人情報をどのように取り扱うかを説明します。本サービスは**個人情報の最小限の収集**と**端末内保存（ローカル優先）**を原則としています。

---

## 1. 原則の要約

- **アカウント・ログインなし** — 本サービスは会員登録を必要としません。
- **位置情報（GPS）権限を要求しません** — 天気は利用者が自分で入力した都市名で照会します。
- **端末のカレンダーは、利用者がオンにした場合にのみ読み取ります** — 選んだカレンダー（Google・Samsungなど）の予定をアプリのカレンダーに一緒に表示する任意機能です。**追加・変更・削除は行わず**、読み取った内容は**端末の外に出ません**。許可しなくても他の機能はそのままご利用いただけます。
- **当社はサーバーを運用していません。** アプリが利用者のデータを送信する当社側のサーバーは存在しません。
- アプリ自身が外部へ送信する通信は**天気の照会ひとつだけ**です（第3項）。
- **音声ロックは音声を録音・保存しません。** ただし話した内容を文字に変換する処理は**端末のオペレーティングシステム**が行い、端末や設定によっては**OSが音声をAppleまたはGoogleのサーバーへ送信して処理する場合があります**（第3項）。
- **AIサービスにデータを送信しません。** ブリーフィングの読み上げは端末自体の音声合成（TTS）で処理され、ネットワークを使用しません。
- **広告を使用しません。**

## 2. 端末内にのみ保存される情報（外部送信なし）

以下の情報は端末のローカルストレージ（`shared_preferences`）およびローカルファイルにのみ保存され、サーバーへ送信されません。

| 項目 | 内容 | 備考 |
| --- | --- | --- |
| アラーム設定 | 時刻・繰り返し・ラベル・サウンド・振動・スヌーズ | |
| バーコードロック | **原文は保存せず SHA-256 ハッシュのみ**保存 | 原文・ハッシュのログ記録は禁止 |
| バーコードのヒント写真 | 登録時に撮影した参考画像 | ローカルファイル。再登録時に削除 |
| 音声ロックのフレーズ | 解除時に話す**文（テキスト）** | 端末にのみ保存；**音声を録音・保存しません** |
| アプリ内予定（カレンダー） | タイトル・時刻・場所・メモ・通知設定 | 端末カレンダーへ**書き出しません** |
| 端末カレンダーの選択 | 重ねて表示するカレンダーの**識別子のみ** | 予定の内容は保存せず、表示のたびに読み取ります |
| 緊急解除PIN | アラームロック解除の最終手段 | **原文は保存せず salt + SHA-256 ハッシュのみ**保存 |
| 読み上げ設定 | 音声・速度・高さ | 端末TTSの設定値 |
| 天気の応答キャッシュ | 直近に取得した予報（最大3時間） | 端末内キャッシュ。都市変更時に削除 |

## 3. 外部サービスへ送信される情報

以下は**該当機能を使用したときにのみ**送信されます。

| 機能 | 送信される情報 | 送信先 | 個人情報の有無 |
| --- | --- | --- | --- |
| 天気の照会 | 利用者が選択した都市の**座標** | MET Norway（ノルウェー気象研究所） | 位置情報権限・アカウント情報なし |
| サブスクリプション決済（提供時） | ストア決済および**匿名のサブスクリプション識別子** | Apple/Google、決済代行（RevenueCat） | アプリは決済・領収書情報を直接保存しません |

- アプリが直接呼び出す外部APIは**上記の天気の照会ひとつだけ**です。決済は各ストアのSDKが処理します。
- 外部通信はすべて **HTTPS** のみで行われます。

**オペレーティングシステムが行う音声認識**

音声でアラームを解除するとき、話した内容を文字に変換する処理はアプリではなく**端末のオペレーティングシステム**（Apple音声認識／Google音声認識）が行います。端末・言語・設定によって、**端末内で処理される場合と、OSが音声を各事業者のサーバーへ送信して処理する場合があります。** この送信はOSが行うものでApple・Googleのプライバシーポリシーに従い、**当社が音声や認識結果を受け取ることはありません。** アプリは音声を録音・保存せず、認識された文字を登録フレーズと照合したうえで直ちに破棄します。

### 送信しないもの

- **ブリーフィングの読み上げ（Pro）** — 読み上げテキストには日付・曜日・天気とともに**予定のタイトルが含まれます**。このテキストは**端末内の音声合成（TTS）エンジンでのみ処理され、外部へ送信されません。** ネットワークに接続していなくても読み上げられます。
- **端末カレンダーの予定** — 選んだカレンダー（Google・Samsungなど）のタイトル・時刻・場所をアプリのカレンダーに表示し、ブリーフィングで読み上げます。この内容は**画面表示と端末内の音声合成にのみ使われ、外部へ送信されません。** アプリは端末カレンダーを**読み取るだけで、追加・変更・削除を行いません**（Androidでは `READ_CALENDAR` のみを要求し、書き込み権限は宣言すらしません）。
- **AIサービス** — 本サービスはいかなるAI提供者にもデータを送信せず、アプリにAI提供者のAPIキーを含みません。
- **当社サーバー** — 当社は利用者のデータを受け取るサーバーを運用していません。
- **AIニュースブリーフィング** — 2026-08-17に製品から削除されました。ニュース関連のデータを収集・送信しません。

> **変更履歴** — 2026-08-23より前のバージョンでは、音声読み上げを当社サーバープロキシ経由で外部の音声合成サービス（OpenAI）へ送信していました。現在は端末内合成に移行し、その送信はなくなり、サーバープロキシも廃止されました。

## 4. 権限について

| 権限 | 目的 | 要求のタイミング |
| --- | --- | --- |
| 通知 | アラーム・予定の通知の表示 | アラームを保存するとき、または予定の通知をオンにするとき |
| カメラ | バーコードロックのスキャン | バーコードロック使用時 |
| マイク・音声認識 | 音声での解除 — 話した内容を文字に変換し、登録フレーズと照合 | 音声でアラームを解除するとき |
| 正確なアラーム（Android） | アラームを定刻に鳴らすため | アラームを保存するとき |
| 電池最適化の除外（Android） | 省電力によるアラームの遅延・不発を防ぐため | 利用者が案内から自ら選択したときのみ |
| 位置情報 | **要求しません** | — |
| 端末カレンダー | **読み取り専用**（任意） — 選んだカレンダーの予定を表示・読み上げ | 「端末のカレンダー」をオンにするとき |

これらの権限は端末の機能を利用するためのものであり、権限を通じて得た情報を外部へ送信することはありません。

権限は初回起動時に一括で要求せず、**該当機能に入ったときにのみ**要求します。権限を拒否しても、その他の機能は引き続きご利用いただけます。

## 5. 保管および破棄

- 上記の情報は、**アプリを削除**するか、アプリ内の**設定 > データの全削除（初期化）**を実行すると端末から削除されます。
- 本サービスはクラウドバックアップを提供しないため（ローカル専用）、端末の変更・再インストール時にはバーコードやPINなどの再設定が必要です。
- 外部サービス（天気・ストア決済）へ送信されたリクエストは各サービスのポリシーに従って処理されます。
- 天気予報の応答は**端末内にのみ**最大3時間キャッシュされ（都市を変更すると即時削除）、当社側には保存されません。

## 6. ログおよびセキュリティ

- バーコードの原文／ハッシュ、発話テキスト、予定の内容、トークン・決済情報、リクエスト／レスポンスの全文は**ログに記録しません。**
- 機微な情報はログ上でマスキング（redaction）します。
- 個人情報保護のため、合理的な技術的・管理的保護措置を講じます。

## 7. 利用者の権利

利用者はいつでもアプリ内の設定から保存されたデータを削除・初期化できます。その他の個人情報に関するご要望は、下記のお問い合わせ先までご連絡ください。

## 8. 子どもの個人情報

本サービスは**満14歳未満の子どもを主な対象としておらず**、子どもの個人情報を故意に収集しません。満14歳未満の子どもが法定代理人の同意なく個人情報を提供したことが判明した場合、当社は遅滞なく当該情報を削除します。本サービスはアカウント・ログインを必要とせず、ほとんどのデータは端末内にのみ保存されます。

## 9. 第三者サービスへのリンク

本ポリシーは、本サービスが利用する第三者（MET Norway、Apple/Google、RevenueCat）の個人情報の取り扱いには適用されません。**端末カレンダーにある予定は各カレンダー提供者（Google・Samsungなど）が管理しており、本サービスはそれを読み取って表示するだけです。**各サービスのポリシーを別途ご確認ください。

## 10. 変更の告知

本ポリシーは法令・サービスの変更に応じて改定されることがあり、改定時は施行日および変更内容をサービス内またはストアを通じて告知します。
