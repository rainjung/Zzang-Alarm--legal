# 개인정보처리방침 (Privacy Policy)

본 방침은 Zzang Alarm(알람짱)(이하 "서비스")이 이용자의 개인정보를 어떻게 취급하는지 설명합니다. 서비스는 **개인정보 최소 수집**과 **기기 내 저장(로컬 우선)**을 원칙으로 합니다.

---

## 1. 원칙 요약

- **계정·로그인 없음** — 서비스는 별도의 회원가입을 요구하지 않습니다.
- **위치(GPS) 권한을 요청하지 않습니다** — 날씨는 이용자가 직접 입력한 도시명으로 조회합니다.
- **기기 캘린더에 접근하지 않습니다** — 일정은 앱 내 로컬에만 저장됩니다.
- **회사는 서버를 운영하지 않습니다.** 앱이 이용자 데이터를 보내는 회사 측 서버는 존재하지 않습니다.
- 앱이 외부로 나가는 통신은 **날씨 조회 하나뿐**입니다(3항). 그 외 데이터는 기기를 벗어나지 않습니다.
- **AI 서비스에 데이터를 보내지 않습니다.** 브리핑 낭독은 기기 자체의 음성 합성(TTS)으로 처리되어 네트워크를 사용하지 않습니다.
- **광고를 사용하지 않습니다.**

## 2. 기기 내에만 저장되는 정보 (외부 전송 없음)

아래 정보는 기기의 로컬 저장소(`shared_preferences`) 및 로컬 파일에만 저장되며 서버로 전송되지 않습니다.

| 항목 | 내용 | 비고 |
| --- | --- | --- |
| 알람 설정 | 시각·반복·라벨·사운드·진동·스누즈 | |
| 바코드 잠금 | **원문을 저장하지 않고 SHA-256 해시만** 저장 | 원문·해시 로깅 금지 |
| 바코드 힌트 사진 | 등록 시 촬영한 참고 이미지 | 로컬 파일, 재등록 시 삭제 |
| 음성 잠금 샘플 | 해제 문장 녹음 | 로컬 저장·삭제 가능 |
| 앱 일정(캘린더) | 제목·시간·장소·메모·알림 설정 | 기기 캘린더와 미동기화 |
| 비상 해제 PIN | 알람 잠금 해제용 최후 수단 | **원문을 저장하지 않고 salt + SHA-256 해시만** 저장 |
| 브리핑 낭독 설정 | 음성·속도·음높이 | 기기 TTS 설정값 |
| 날씨 조회 결과 캐시 | 최근 조회한 예보(최대 3시간) | 기기 내 캐시, 도시 변경 시 삭제 |

## 3. 외부 서비스로 전송되는 정보

아래는 **해당 기능을 사용할 때에만** 전송됩니다.

| 기능 | 전송되는 정보 | 수신 측 | 개인정보 포함 여부 |
| --- | --- | --- | --- |
| 날씨 조회 | 이용자가 선택한 도시의 **좌표** | MET Norway(노르웨이 기상청) | 위치 권한·계정 정보 없음 |
| 구독 결제 (제공 시) | 스토어 결제 및 **익명 구독 식별자** | Apple/Google, 결제 대행(RevenueCat) | 앱은 결제·영수증 정보를 직접 저장하지 않음 |

- 앱이 직접 호출하는 외부 API는 **위 날씨 조회 하나뿐**입니다. 결제는 각 스토어 SDK가 처리합니다.
- 모든 외부 통신은 **HTTPS**로만 이루어집니다.

### 전송하지 않는 것

- **브리핑 낭독 (Pro)** — 낭독 텍스트에는 날짜·요일·날씨와 함께 **일정 제목이 포함**됩니다. 이 텍스트는 **기기 안의 음성 합성(TTS) 엔진에서만 처리되며 외부로 전송되지 않습니다.** 네트워크가 끊겨 있어도 낭독됩니다.
- **AI 서비스** — 서비스는 어떤 AI 제공자에게도 데이터를 보내지 않으며, 앱에 AI 제공자의 API 키를 포함하지 않습니다.
- **회사 서버** — 회사는 이용자 데이터를 받는 서버를 운영하지 않습니다.
- **AI 뉴스 브리핑** — 2026-08-17 제품에서 제거되었습니다. 뉴스 관련 데이터를 수집·전송하지 않습니다.

> **변경 이력** — 2026-08-23 이전 버전은 음성 낭독을 회사 서버 프록시를 거쳐 외부 음성 합성 서비스(OpenAI)로 보냈습니다. 현재는 기기 내 합성으로 전환되어 해당 전송이 없어졌고, 서버 프록시도 폐지되었습니다.

## 4. 권한 안내

| 권한 | 목적 | 요청 시점 |
| --- | --- | --- |
| 알림 | 알람·일정 알림 표시 | 알람을 저장할 때, 또는 일정 알림을 켤 때 |

| 배터리 최적화 제외 (Android) | 절전 모드에서 알람이 지연·누락되지 않도록 | 이용자가 안내에서 직접 선택할 때 |
| 위치 | **요청하지 않음** | — |
| 기기 캘린더 | **요청하지 않음** | — |

위 권한들은 기기 기능을 쓰기 위한 것이며, 권한을 통해 얻은 정보를 외부로 전송하지 않습니다.

권한은 최초 실행 시 일괄 요청하지 않고 **해당 기능에 진입할 때에만** 요청합니다. 권한을 거부해도 나머지 기능은 계속 사용할 수 있습니다.

## 5. 보관 및 파기

- 위 정보는 이용자가 **앱을 삭제**하거나, 앱 내 **설정 > 데이터 전체 삭제(초기화)**를 실행하면 기기에서 삭제됩니다.
- 서비스는 클라우드 백업을 제공하지 않으므로(로컬 전용), 기기 변경·재설치 시 바코드·PIN 등은 재설정이 필요합니다.
- 외부 서비스(날씨·스토어 결제)로 전송된 요청은 각 서비스의 정책에 따라 처리됩니다.
- 날씨 예보 응답은 **기기 안에만** 최대 3시간 캐시되며(도시를 바꾸면 즉시 삭제), 회사 측에는 저장되지 않습니다.

## 6. 로깅 및 보안

- 바코드 원문/해시, 발화 텍스트, 일정 내용, 토큰·결제 정보, 전체 요청/응답 본문은 **로그로 남기지 않습니다.**

## 8. 아동의 개인정보
